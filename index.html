// Architektur: Version 1.0 vs. Version 2.0

Version 1.0 (Aktueller Stand)

  • Dediziertes Lkw-Container Formular
  • Supabase Cloud-Sync & Verschlüsselung
  • Offline-First ServiceWorker Engine

Version 2.0 (Geplante Features)

  • Dynamische Benutzerfelder (Gewerbe-Universal)
  • Flexible Schema-Konfiguration
  • Erweiterte Export-Engine (CSV / Excel / PDF)
